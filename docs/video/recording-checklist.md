# Демо-видео PRITOK: чек-лист записи

Один демо-выпуск проходит всю жизнь примерно за 17 минут. Сырой материал — 18–22 минуты, если ставить запись на паузу в местах ожидания (отмечены ⏸).

## До записи

- [ ] Браузер в отдельном профиле: без закладок, расширений с адресами кошельков и уведомлений. Масштаб 110–125%, окно 1920×1080.
- [ ] Адресная строка видна всё время: `pritok-sol.vercel.app` и `explorer.solana.com` — доказательство живого продукта.
- [ ] В кадре никогда не открывать: Vercel (переменная `DEMO_KEYS`), `client/.keys`, `.env*`, терминал, ссылки RPC с ключом Helius.
- [ ] Вкладки:
  1. https://pritok-sol.vercel.app/demo?lang=en — экран выпуска;
  2. https://pritok-sol.vercel.app/bonds?lang=en — список выпусков (для кадра «Issuer debt»);
  3. пустая вкладка под Explorer.
- [ ] Проверить, что последний выпуск в списке не висит с долгом («Issuer debt 0»). Брошенный выпуск портит список и портфель.
- [ ] Слайды 0:00 и 2:48 готовы (см. [scenario.md](scenario.md)).
- [ ] Часы записи: держать на втором мониторе секундомер с момента T0.

## Расписание выпуска

T0 — нажатие **Create issue** в форме нового выпуска. Выпуск стартует примерно через 13 секунд после T0. Это время на создание и размещение, оно гуляет ±10 с. Точное время показывает плашка-часы в шапке: «to … record date mm:ss».

| Событие | ≈ после T0 | Что успеть до него |
|---|---|---|
| Закрытие подписки | 1:13 | — |
| Дата фиксации купона 1 | **3:43** | перевод Айгерим → Болат (10); эмитент вносит купон 1; объявить амортизацию 20% на купон 2 |
| Выплата купона 1 | **4:13** | — |
| Дата фиксации купона 2 и амортизации | **7:43** | эмитент вносит купон 2 |
| Выплата купона 2 и амортизации | **8:13** | — |
| Дата фиксации купона 3 | 11:43 | эмитент вносит **75%** купона 3 |
| Выплата купона 3 | **12:13** | — |
| Дата фиксации купона 4 и погашения (переводы закрываются) | 15:43 | эмитент вносит купон 4 и номинал |
| Выплата купона 4 и погашение | **16:13** | — |

Суммы при выпуске по умолчанию (1 000 облигаций по 100 000 ₸, 16%):
- купон 1 и 2 — 8 000 000 ₸;
- амортизация 20% — 20 000 000 ₸;
- купон 3 и 4 после амортизации — 6 400 000 ₸, 75% — 4 800 000 ₸;
- погашение — 80 000 000 ₸.

## Порядок записи

**Сцена 0:12 · Эмитент, создание** (T0 − 0:20 … T0 + 0:30)
1. Вкладка 1 → **New demo issue** → в форме оставить значения по умолчанию, медленно провести курсором по сводке («Coupon per bond 8 000 ₸»).
2. **Create issue** — это T0, запустить секундомер.
3. Роль **Public**: реестр 300 / 200 / 500, таймлайн выпуска.

**Сцена 0:30 · Explorer, минт** (T0 + 0:30 … 1:30)
4. Журнал операций внизу → любая транзакция размещения → «transaction ↗».
5. В Explorer в списке аккаунтов транзакции открыть минт облигации (Token-2022, 0 decimals) → раздел расширений: *Default Account State: Frozen*, *Permanent Delegate*. Задержать кадр на 3 секунды.

**Сцена 0:42 · Инвестор, перевод до фиксации** (T0 + 1:30 … 2:30)
6. Если «Now» предлагает закрыть подписку — нажать.
7. Роль **Investor** → Aigerim S. → «Free-of-payment transfer»: кому — Bolat N., 10 → **Transfer**.

**Сцена 1:04 · Эмитент, купон 1 и амортизация** (T0 + 2:30 … 3:30)
8. Роль **Issuer** → по «Coupon 1» → **Fund 8 000 000 ₸**.
9. «Early partial redemption»: событие — Coupon 2, доля 20 → **Announce and fund**. Должно пройти до 7:43; лучше сейчас.

⏸ **Пауза** до T0 + 3:45.

**Сцена 0:42 (продолжение) · перевод после фиксации** (T0 + 3:45 … 4:10)
10. Investor → Bolat N. → Transfer 10 → Zhibek Fund.
11. Public → «Holder register as of»: **Coupon 1** → 290 / 210 / 500, затем **Now** → 290 / 200 / 510. Медленно, это ключевой кадр механизма даты фиксации.

**Сцена 1:04 · Оператор, выплата купона 1** (T0 + 4:15 … 5:30)
12. Нажать на строку «Coupon 1» в Corporate actions → панель расчёта: units × 8 000 ₸, этапы Created / Register fixed / Funded.
13. Роль **Operator** → консоль → **Execute payout** у Coupon 1 → «3 of 3».
14. **Report** → квитанция одного держателя «↗» → Explorer → прокрутить до **Program Instruction Logs**: `Instruction: PayHolder` × 3. Задержать кадр.
15. Issuer → по «Coupon 2» → **Fund 8 000 000 ₸**.

⏸ **Пауза** до T0 + 8:15.

**Сцены 1:28 и 1:48 · амортизация и банк** (T0 + 8:15 … 9:30)
16. Investor → Bolat N. → по купону 2 **To bank**.
17. Operator → **Execute payout** по Coupon 2 (оставшимся держателям) и по «Amortization 20%».
18. Operator → «Bank payouts to confirm» → ввести номер платёжки (например, `PP-2026-1012-001`) → **Confirm**.
19. Карточка выпуска: номинал 80 000 ₸, «amortization». Explorer: лог амортизации.
20. Issuer → по «Coupon 3» → **Fund 75%**.

⏸ **Пауза** до T0 + 12:15.

**Сцена 1:48 · дефолт и его погашение** (T0 + 12:15 … 13:30)
21. Operator → **Record default** по Coupon 3 → красное «Issuer debt» в карточке.
22. Вкладка 2 (список выпусков) → обновить → статус «Issuer debt».
23. Issuer → по Coupon 3 → **Fund** остаток (1 600 000 ₸) → Operator → **Execute payout**.
24. Issuer → внести купон 4 и погашение (**Fund** по обоим).

⏸ **Пауза** до T0 + 16:15. Если осталось больше двух минут, можно снять DvP: Investor → Zhibek Fund → «Sell: delivery versus payment» → Aigerim S.; только до T0 + 15:43.

**Сцена 2:12 · погашение** (T0 + 16:15 … 17:30)
25. Investor: блок перевода — «Transfers are closed after the maturity record date…».
26. Operator → **Execute payout** по Coupon 4 → **Execute redemption** по Maturity.
27. Карточка: Outstanding 0, «1 000 redeemed and burned».
28. Журнал → «Operator redeemed … bonds burned» → Explorer → Program Logs: `Instruction: RedeemFor`, вложенный `Burn` программы Token-2022.

**Сцена 2:32 · реестр и портфель** (T0 + 17:30 … 18:30)
29. Public → прощёлкать «Holder register as of»: Coupon 1 … Maturity; журнал операций со ссылками «transaction ↗».
30. Шапка → **Portfolio** → Bolat N.: received, calendar, history.

## После записи

- Выпуск закрыт полностью: долгов не осталось, иначе он повиснет в списке.
- Прислать путь к mp4. Дальше: Whisper → раскадровка ffmpeg → список кусков с ускорением → черновик ≤ 3:00 → озвучка по [voiceover.md](voiceover.md), плашки ролей, вшитые субтитры.
